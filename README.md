# Зберігач медіа

Розширення для Chrome: знаходить відео й аудіо на відкритій сторінці та зберігає їх на диск, зокрема потокове відео HLS (`.m3u8`).

Без облікових записів, лімітів, реклами й зовнішніх серверів. Усе працює локально у вашому браузері, розширення нікуди не надсилає дані.

Розширення не має залежностей і не потребує збірки: це звичайні файли JavaScript для Chrome (Manifest V3).

## Встановлення

1. Відкрийте в Chrome адресу `chrome://extensions`.
2. Праворуч угорі ввімкніть **«Режим розробника»**.
3. Натисніть **«Завантажити розпаковане розширення»** і виберіть папку з цим репозиторієм (там, де лежить `manifest.json`).
4. Закріпіть іконку на панелі: значок пазла → шпилька біля «Зберігач медіа».

Після змін у коді натисніть на картці розширення кнопку оновлення ↻.

## Як користуватися

1. Відкрийте сторінку з відео і **запустіть відтворення**. Розширення бачить лише те, що сторінка вже почала завантажувати.
2. Цифра на іконці показує, скільки медіафайлів знайдено. Натисніть на іконку, щоб відкрити список.
3. **Звичайний файл** (mp4, webm, mp3…) зберігається одразу через список завантажень Chrome.
4. **Потокове відео (HLS)** відкривається на окремій вкладці. На ній можна:
   - вибрати якість і звукову доріжку;
   - змінити назву файлу;
   - натиснути «Почати завантаження».

   Вкладку не закривайте до завершення.
5. Опція **«Записувати одразу у файл на диску»** зберігає дані у файл частинами, тому не потребує пам'яті під усе відео. Рекомендована для довгих відео. Chrome попросить вибрати папку.

## Що вміє

- Знаходить медіа за адресою і типом вмісту. Окремі шматочки потоку (`.ts`, `.m4s`) не засмічують список.
- Збирає HLS:
  - сегменти MPEG-TS → файл `.ts`;
  - fMP4 (`init.mp4` + `.m4s`) → файл `.mp4`;
  - фрагменти за діапазоном байтів (`EXT-X-BYTERANGE`).
- Розшифровує стандартне шифрування потоку AES-128, ключ до якого віддає сам сайт.
- Качає кілька сегментів паралельно, повторює запити при збоях і записує сегменти строго по порядку.
- Підставляє адресу сторінки як `Referer`. Без цього частина сайтів не віддає відео. Це діє лише на запити вкладки завантаження.
- Окрему звукову доріжку зберігає другим файлом.
- Налаштування:
  - мінімальний розмір файлу;
  - ігноровані домени;
  - папка в «Завантаженнях»;
  - назва файлу за заголовком сторінки;
  - кількість одночасних з'єднань;
  - лічильник на іконці.

## Чого не вміє (свідомо або поки що)

- **DRM** (Widevine, FairPlay, `SAMPLE-AES`): такі відео не завантажуються, і розширення прямо про це повідомляє.
- **DASH (`.mpd`)** і запис з екрана: можливий наступний етап.
- Відео й окрему звукову доріжку розширення не зводить в один файл. Їх можна відтворити разом у VLC або поєднати командою:
  ```bash
  ffmpeg -i "назва.video.ts" -i "назва.audio.aac" -c copy "назва.mp4"
  ```
- Файл `.ts` відтворюють VLC, mpv і більшість програвачів. Щоб отримати `.mp4` без перекодування:
  ```bash
  ffmpeg -i "назва.ts" -c copy "назва.mp4"
  ```

Завантажуйте лише те, на що маєте право: власні матеріали, відкриті архіви, контент із дозволом автора.

## Будова

| Файл | Призначення |
| --- | --- |
| `manifest.json` | Опис розширення (Manifest V3) |
| `background.js` | Стежить за мережевими відповідями вкладок, веде список знайденого, лічильник на іконці |
| `popup.html/js` | Вікно зі списком файлів |
| `download.html/js` | Вкладка завантаження HLS: вибір якості, прогрес, збереження |
| `options.html/js` | Налаштування |
| `lib/media.js` | Розпізнавання медіа, назви файлів, транслітерація для запасної назви |
| `lib/hls-playlist.js` | Розбір списків відтворення `.m3u8` |
| `lib/downloader.js` | Паралельне завантаження з повторами й упорядкованим записом |
| `lib/aes.js` | Розшифрування AES-128 (WebCrypto) |
| `_locales/uk/messages.json` | Усі тексти інтерфейсу |

## Перевірка

Модульні тести (Node.js 22+):

```bash
node --test tests/*.test.mjs
```

Наскрізна перевірка в Chromium через Playwright. Скрипт `make-site.sh` генерує через ffmpeg тестовий сайт:
- звичайний mp4;
- HLS без шифрування;
- HLS з AES-128;
- HLS у форматі fMP4.

Потім `e2e.mjs` завантажує розширення в Chromium і порівнює збережені файли з еталонами байт у байт:

```bash
tests/make-site.sh /tmp/ms-site
LANG=C.UTF-8 node tests/e2e.mjs /tmp/ms-site
```
